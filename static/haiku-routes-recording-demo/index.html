Haiku Routes: GPS recording

Android package com.haikuroutes.app, version 1.1.8 (14). This is a genuine Android 16 emulator recording using simulated coordinates from a public hiking trail. It contains no personal location data.

The demonstration shows the recording disclosure, notification permission, user-started recording, the persistent notification while the app is in the background, return to the growing track, screen-off recording, and the pause and finish controls.
